# 实测验证手册：回测数据源扩展（分支 `feature/backtest-datasource-expansion`）

- 写给：在另一台电脑/另一网络环境执行实机测试的人（或 Agent）
- 目的：本机网络验证受限（GitHub HTTPS 被墙、中国货币网限流惩罚窗口未过），以下测试在本手册环境完成即为最终交付验收
- 分支：`feature/backtest-datasource-expansion`（HEAD `c4e40e8`），基于 main 的 22 个提交，已推送到 origin
- 设计文档（验收依据）：`docs/superpowers/specs/2026-09-05-回测数据源扩展-design.md` §九
- ⚠️ **重要前置**：请勿在短时间反复运行网络测试——第 4 节的"按发行人查债"直连中国货币网，该站点按 IP 限新建连接数（HTTP 421），每个查询 31 个串行请求、约 10 秒。每个查询之间**间隔至少 1 分钟**，每个用例只跑一次，失败不要重试（重试会延长 IP 惩罚窗口，数小时）。

## 4. 交易规则参数表（spec 验收 4，纯本地不联网）

```bash
python -c "
from local_datasource.providers.rules import query_trading_rules
import pandas as pd
# 三组历史边界
for as_of, expect in [('2021-06-01', '0.001'), ('2024-01-01', '0.0005')]:
    query_trading_rules(market='a', as_of=as_of, file_path='r.csv')
    row = pd.read_csv('r.csv'); row = row[row['parameter'].str.contains('印花税')]
    v = row.iloc[0]['value']
    print(f'as_of={as_of} 印花税={v}', 'OK' if str(v).rstrip('0') == expect.rstrip('0').rstrip('.') or float(v)==float(expect) else 'MISMATCH!')
query_trading_rules(market='a', file_path='r_now.csv')   # 不传 = 现行
print('现行印花税 value:', pd.read_csv('r_now.csv').query(\"parameter.str.contains('印花税')\").iloc[0]['value'])
# 商品期货引导行
_, s = query_trading_rules(market='commodity_futures', file_path='r_cf.csv')
print('commodity_futures 引导行 OK:', '结算参数' in s)
# 2026 两个新变更
query_trading_rules(market='a', as_of='2026-08-01', parameter='ST', file_path='r_st.csv')
print('ST rows:', len(pd.read_csv('r_st.csv')))
query_trading_rules(market='margin', as_of='2026-08-01', file_path='r_mg.csv')
print('margin rows:', len(pd.read_csv('r_mg.csv')))
"
```

预期：印花税 2021→0.001（仅卖出）、2024→0.0005、现行→0.0005；commodity_futures 返回引导不报错。

## 回报格式

逐节回复通过/失败/受限三态，模板：

```
环境: <OS> / <python 版本> / akshare 版本(python -c "import akshare;print(akshare.__version__)")
0. 离线基线: <pass/fail + 数字>
1. 全球利率: 美债<最早日期/行数> EFFR<最新日期> VIX<最早日期> dxy<成功源或不可达>
2. 汇率: mid<最早日期/行数/100外币口径确认> usdcnh<通过/不可达>
3. 现货: sge<行数> sy<行数/基差列> 超1年报错<OK/fail>
4. 规则表: 三组 as_of 值<实际值> 商品期货引导<OK> ST/融资保证金行数<N>
5. 对齐: <列名/行数>
6. 缓存: FETCH/SKIP/FAIL<实际输出> manifest<存在与否>
7. 发行人查债: <1行 2380205 / 报错原文>
8. MCP 冒烟: <通过/失败>
结论: <全部通过 / 哪些项受限网络影响(注明网络现象) / 哪些项失败(附报错原文)>
```

**判读基准**：4/5/6/8 四项纯本地或本地服务，必须全过；1/2/3/7 的"不可达"类报错若确认是网络环境（dxy/Yahoo/货币网 421），标记"受限"不算失败，但要把报错原文回报——尤其第 7 项是本分支唯一的新修复，421 需要换时段再验一次。
