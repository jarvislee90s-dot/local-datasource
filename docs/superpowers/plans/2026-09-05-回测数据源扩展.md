> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 `docs/superpowers/specs/2026-09-05-回测数据源扩展-design.md` 交付 5 个新工具（全球利率/汇率/现货/规则参数表/对齐合并）+ download CLI 与本地缓存 + 存量文档实测修正，存量 11 工具零改动。

**Architecture:** 沿用现有模式——每个资产类别一个 provider 模块、`query_xxx(...) -> tuple[str, str]` 唯一事实源、`server.py` 薄注册、统一 CSV 落盘 + 前 5 行预览（`formatters.format_csv_output`）。缓存是独立的纯函数模块（`cache.py`），只被 CLI 使用，MCP 查询路径完全不感知。本计划**只锁接口契约与验收**，模块内部构造（私有函数拆分、重试实现方式、代码组织）由执行者自定。

**Tech Stack:** 现有依赖不变（akshare / yfinance / pandas / pyyaml / requests / mcp）。不新增第三方依赖；CBOE 与纽约联储直连用 requests。

## 计划使用说明（重要）

本计划与典型 step-by-step 计划不同：**每个任务给出 [契约] 与 [验收]，不给出实现代码**。执行者拥有实现自由，但以下三类内容是硬约束，验收时逐条检查：

1. **函数签名与返回形态**——[契约] 中的签名必须一致（参数名参与 MCP schema 生成，不能改）。
2. **kind 枚举与参数 schema**——server.py 注册的 inputSchema 片段（本计划已给出）不得增删必填项。
3. **错误语义**——凡 [契约] 注明"报错"的行为，必须是 `ValueError` 系（`CoverageError` 继承它）且文案含指定关键词；不许静默降级。

**仓库既有约定（执行者必读）：**

- 测试写在本地 `tests/`（`.gitignore` 已忽略，**不提交**）；集成冒烟测试用 `pytest.mark.skipif` 标记网络门控。
- akshare 调用在单测中一律 `monkeypatch` 模拟，不连网。
- `format_csv_output(df, file_path)` 是唯一落盘出口（utf-8-sig、自动建目录、返回预览）。
- 提交遵循现有 message 风格（`feat:`/`docs:`/`test:` 前缀，中文描述）。
- 硬依赖红线（来自 `docs/消费契约-quant-chart.md`，M2 会再测）：`CoverageError` 类型与 message 语义；被消费表列名（期货单合约日线 `date,open,high,low,close,volume,hold,settle`；分钟表 `datetime,open,high,low,close,volume`，期货多 `hold`）。

```
└── cli.py                         # [新] download 子命令（M3）
```

方法约定（架构级，实现自由）：

- **工具描述预算**：每个新注册工具的 description 控制在约 100 字（一句话用途 + kind 说明 + 关键限制如深度/单位/慢源），保障 Agent 读取效率（spec §四）。
- **列名规范**：全部新工具输出英文 snake_case，日期列统一 `date`（源为中文列或 `日期`/`DATE` 时在 provider 内映射）。
- **日期过滤**：复用 `providers/common.filter_by_date` 或等效实现。
- **回退链**（仅 DXY 需要）：provider 内部实现"首选源 → 回退源 → 报错"三段式，报错文案含"该源在当前网络不可达"。
- **直连源**（CBOE/纽约联储）：requests + 30 秒超时 + 重试一次，失败报网络指引。
- **慢源限区间**（生意社）：超过 1 年报错，文案含"缩小范围"。
- **align_series**：先识别各 CSV 首列日期（`date`/`datetime`/`日期`），先重采样后合并；`week` 按 W-FRI、`month` 按 M，取每期最后一行。
