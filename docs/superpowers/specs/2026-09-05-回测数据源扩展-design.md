# 回测数据源扩展设计：全球利率/汇率/现货 + 规则参数表 + 通用后处理 + 日线缓存 CLI

- 日期：2026-09-05
- 来源：brainstorming 会话（需求快照经用户逐项确认；四份调研报告支撑，全文见附录文件）
- 状态：待实现
- 范围：新增 5 个 MCP 工具 + download CLI 与缓存层 + 存量文档实测修正；**存量 11 个工具行为零改动**（quant-chart 契约不受影响）

## 一、背景与目标

用户为证券从业人员，回测分两种情境：

1. **快速验证**：Agent 经 MCP 对话式完成——用自然语言描述宏观判断 + 技术形态（上行通道、筹码密集区支撑/压力、急浪等），Agent 拉数、写回测代码、出结论。
2. **模拟盘**：CLI 批量取数落本地，自写代码按真实约束（T+1、涨跌停、整手、佣金、印花税）跑历史模拟。

本仓库定位为统一数据源。当前 11 个工具已覆盖 A/HK/US 股票、境内债券/可转债、国内期货/指数/ETF/期权、美股全球资产、世界银行宏观、arXiv、代码归一化。经需求澄清，本轮补齐四类能力：**美国/全球利率与波动率、汇率与国内商品现货、带生效区间的交易规则参数表、通用后处理与日线缓存**。

## 二、需求快照（已确认）

| 维度 | 结论 |
|---|---|
| 消费形态 | Agent(MCP) 快速验证 + CLI 批量缓存供模拟盘/脚本；规则**执行**留在用户引擎，数据源只供**参数** |
| 新增数据类别 | 美国全球利率与波动率（Fed/美债/DXY/VIX）、汇率（中间价/在岸/离岸/交叉盘）、国内商品现货（与期货主连对照） |
| 预处理边界 | 原始数据 + 少量通用后处理（对齐合并、重采样）；指标与筹码分布计算留消费端 |
| 缓存 | 日线批量缓存 + CLI 按清单下载；MCP 查询可选 cache-first（`use_cache` 默认 false） |
| 规则参数表 | 带生效区间；`as_of` 历史日期取当时生效参数（历史真实回测），缺省取今天（现行规则套历史模拟）——两种情境一个参数覆盖 |
| 不做 | 中国宏观月频流、北向/两融/龙虎榜等资金面、MA/MACD/筹码分布等指标层、期权/转债策略深度扩展、分钟长历史累积、Qlib/vectorbt 格式导出 |

## 三、架构决策

**方案：最小增量（A）+ 三条防膨胀措施**（用户在 A/B/C 对比后选定）。

- 沿用"一个资产类别一个聚合 tool + kind 分流"，11 → 16 个 tool。
- 不引入 registry/统一查询入口（方案 B）：数据集参数天然异构，通用 dict 参数会丢 schema 精度、伤 Agent 选择准确性；当前规模不需要。**演进路径保留**：provider 函数是唯一事实源，tool 永远薄封装，将来迁 registry 是机械搬移。
- 不采用 freqtrade 式 datadir/feather（方案 C）：与"Agent 读 CSV"的消费形态不匹配。缓存格式用 **CSV + manifest**。

防膨胀三措施：

1. provider 函数唯一事实源（现状保持），tool 层薄封装（现状保持）。
2. tool 描述预算：一句话用途 + kind 枚举说明 + 输出契约，约 100 字内。
3. kind 优先于新 tool：新数据先落既有 tool 的 kind（本轮 Fed/美债/DXY/VIX 共用一个 tool 即首例）。

## 四、组件设计

### 4.1 `query_global_rates`（新 provider：`providers/global_rates.py`）

| kind | 首选源 | 回退 | 实测覆盖（2026-09-05） | 输出列 |
|---|---|---|---|---|
| `us_treasury` | `bond_zh_us_rate`（东财 datacenter 端点，实测可达） | `bond_gb_us_sina`（13 期限，仅近 1000 交易日） | 2/5/10/30Y 自 1990-12-19 日频 | `date, us_2y, us_5y, us_10y, us_30y, us_10y_2y` |
| `fed_rate` | 纽约联储官方 EFFR API（`markets.newyorkfed.org`，实测可达） | 无（FRED 需代理不作回退） | EFFR 日频官方序列。金十 `macro_bank_usa_interest_rate` 2025-09 后停更（NaN），弃用 | `date, effr` |
| `dxy` | `index_global_hist_em("美元指数")`（东财 push2his 端点，**本机网络实测被拒**） | yfinance `DX-Y.NYB` | 东财口径 1986-01-09 起；Yahoo 口径较短 | `date, open, high, low, close` |
| `vix` | CBOE 官方 CSV 直连（`cdn.cboe.com/.../VIX_History.csv`，实测 200 OK，免 key） | yfinance `^VIX` | 1990-01-02 起日频。akshare `index_vix` 已在 1.10.43 移除，勿信旧教程 | `date, open, high, low, close` |

参数：`kind`（必填）、`file_path`（必填）、`start_date/end_date`（可选，默认全量；`fed_rate` 默认近 1 年）、`tenure`（仅 `us_treasury`：`all` 默认 / `2y/5y/10y/30y` 走东财源 / `3m/6m/1y/7y/20y` 等走新浪源取近 1000 日）。

实现要点：CBOE/NY Fed 用 `requests` 直连（UA + 30 秒超时 + 重试一次）；DXY 的东财→yfinance 回退链沿用 `query_yfinance` 的风格，链耗尽后报错文案含"该源在当前网络不可达"与建议动作。

### 4.4 `query_trading_rules`（新 provider：`providers/rules.py` + 静态表）

**数据形态**：随包分发的版本化静态表 `assets/trading_rules.yaml`，每行字段：

```yaml
- market: a            # a / cffex / treasury_futures / etf / margin / option / hk_connect
  parameter: stamp_duty
  scope: ""            # 适用板块/品种细分（如 mainboard_star 创业板/科创板）
  value: "0.0005"
  unit: proportion     # proportion / percent / yuan_per_lot / yuan_per_share / flag / rule
  basis: trade_amount  # 费基口径（trade_amount / par_value / per_lot / none）
  effective_from: "2023-08-28"
  effective_to: null   # null = 至今
  source: "财政部 税务总局公告2023年第39号"
  last_verified: "2026-09-05"
  confidence: official # official / media / to_verify / market_estimate
  note: "仅卖出方征收"
```

**查询语义**：`market`（必填）+ `as_of`（可选，默认今天）→ 返回该日期当天生效的参数行全集；`parameter` 可选过滤。历史真实回测传历史 `as_of`，现行规则套历史缺省即可——两种情境天然覆盖。`effective_from <= as_of < effective_to`（`effective_to` 为 null 视为无穷大）。

**收录范围**（初始内容，全部区间数据见附录 B；`to_verify` 行须在 M4 实现时对照官方公告原文复核后降级或修正）：

1. A 股印花税（双边/单边属性随区间建模，13 档）
2. 过户费（4 档；2015-08-01 起费基由面值改金额，`basis` 字段切换）
3. 经手费 + 证管费（含"佣金代收、勿重复计费"的 note）
4. 红利税差别化档位（20/10/5/0 四段）
5. 涨跌幅矩阵（板块×日期：主板 10% 自 1996-12-16、ST 5%→**2026-07-06 起 10%**、创业板 2020-08-24 起 20%、科创板 20%、北交所 30%、新股首日规则、2016 熔断 4 天特殊区间）
6. T+1 交收制度开关（1995-01-01 分界 + T+0 品类白名单：跨境/债券/货币/黄金 ETF）
7. 中金所股指期货保证金与平今仓手续费完整时间线（IF/IH/IC/IM 分品种，非套保口径；节假日临时调整不入表、note 说明）
8. 国债期货保证金/平今费（品种少变更少）
9. 融资保证金最低比例（50%→100%→80%→**2026-01-19 起 100%**）
10. ETF 期权/股指期权手续费（各 1-2 次变更）
11. 港股通红利税（H 股 20%、红筹综合约 28% 逻辑入 note）

**明确排除**（查询这些时返回引导性提示而非报错，风格同 `issuer_finance` 城投处理）：

- 券商佣金/期货公司加收/两融利率：市场化无官方时间线。表内以 `confidence: market_estimate` 给时代分段参考默认值（万10→万3→万1）+ 官方上限 3‰、最低 5 元（2002-05-01 起有效），note 注明可被用户覆盖。
- 商品期货各合约手续费/保证金：品种×合约×时段三维频繁变动，无法穷举；提示查交易所当日结算参数。

**维护**：表变更走包版本 + CHANGELOG；两个 2026 年新变更（融资保证金、ST 涨跌幅）已收录，`last_verified` 标注核验日。

### 4.5 `align_series`（新模块：`providers/align.py`）

多 CSV 按日期对齐合并 + 重采样，产出宽表 CSV。参数：

- `file_paths`（必填，≥2 个，须为本库产出的 CSV，首列 `date/datetime/日期` 自动识别）
- `columns`（可选，与 file_paths 对应，默认各取 `close`；无该列时报错）
- `names`（可选，输出列名，默认文件名去扩展名）
- `align`：`outer` 默认 / `inner`；`fill`：`none` 默认 / `ffill`
- `resample`：`none` 默认 / `week`（W-FRI）/ `month`（M），取每期最后一行（先重采样后合并）
- `file_path`（必填，输出）

### 4.6 缓存与 download CLI（新模块：`cache.py` + `cli.py`）

**命令**：`local-datasource download --config assets.yaml [--data-dir DIR] [--force]`。复用现有 `local-datasource` console script 做子命令分发：不带子命令时直接启动 MCP server（向后兼容），带 `download` 子命令时执行批量下载。

**清单文件**（用户手工维护的"关注池"）：

```yaml
data_dir: ./datasource-cache
assets:
  - tool: query_stock
    args: {ticker: "600519", market: a, adjust: qfq}
    start_date: "2015-01-01"      # 可选
  - tool: query_index
    args: {symbol: "000300"}
  - tool: query_global_rates
    args: {kind: us_treasury}
```

**布局**：`<data_dir>/<tool>/<key>.csv` + 同名 `.manifest.json`。`key` 由 `providers/common.cache_key(tool, args)` 生成：按 tool 定制模板、参数按名排序拼接、非法字符转 `_`（如 `a_600519_qfq`、`us_treasury`），保证外部脚本可预测路径。manifest 字段：`tool, key, args, rows, first_date, last_date, last_fetched("YYYY-MM-DD HH:MM")`。

**刷新语义**：fresh = `last_fetched` 为今天；fresh 跳过（打印 SKIP），stale **全量重拉覆盖**。说明：各源单标的全量耗时秒级（实测 2-5 秒），全量刷新比尾部拼接简单可靠、避免缝隙；"增量"体现为"新鲜项跳过"。`--force` 全量重拉。

**`@cacheable` 装饰器（`providers/common.py`）**：

- `use_cache` 参数加入 13 个查询类工具 schema（存量 10 个行情/数据类 + 新增 `query_global_rates`/`query_fx`/`query_spot`），**默认 false、零副作用**（不读不写缓存目录）——存量行为与 quant-chart 契约完全不变。
- `use_cache=true`：命中（key 匹配 + fresh）→ 直接读缓存 CSV 并生成预览 summary 返回；miss/stale → 回源取数、写调用方 `file_path`、**同时写缓存副本与 manifest**（write-through）。
- 缓存范围：全部行情类工具；`resolve_stock_code`（低价值）、`align_series`（后处理）、`query_trading_rules`（本地静态表本就即时）不参与。
- `data_dir` 来自 config.yaml 新增 `cache.data_dir`，默认 `./datasource-cache`。

## 六、错误处理

- fallback 链耗尽后报错文案含"该源在当前网络不可达 + 建议动作"（如 DXY→yfinance 建议检查代理）。
- 慢接口（生意社、中行牌价、东财美债分页）在 tool 描述标注预期耗时；`sy` 超过 1 年区间直接报错要求缩小范围。
- 直连源（CBOE/NY Fed）30 秒超时 + 重试一次，失败报网络指引。
- `us_treasury` 的 `tenure` 与 kind 枚举非法值显式报错，不静默降级（沿用现有枚举处理风格）。
- `align_series`：文件不存在/首列无日期列/`columns` 指定列缺失 → 显式报错。

## 七、测试策略

- **单测（无网络）**：trading_rules 表加载与 `as_of` 区间判定（含边界：恰好生效日、失效日前一天、跨区间参数）；`cache_key` 稳定性；`@cacheable` 命中/miss/写回/`use_cache` 缺省时零副作用；`align_series` 对齐/重采样/ffill/inner/错误路径；新 provider 参数归一（tenure/pair/symbol）。
- **集成冒烟（需网络，可 skip 标记）**：每个新 kind 至少 1 条真实调用，断言行数与关键列。
- **契约回归**：存量 11 个工具注册名与行为零改动；quant-chart 硬依赖（CoverageError 语义、被消费表列名/日期格式）显式断言。

## 八、里程碑

- **M1**：`query_global_rates` + `query_fx`（含 CBOE/NY Fed 直连 provider、DXY 回退链）

## 九、风险与开放问题

| 风险 | 应对 |
