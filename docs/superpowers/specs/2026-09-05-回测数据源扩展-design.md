# 回测数据源扩展设计：全球利率/汇率/现货 + 交易规则参数表 + 通用后处理 + 日线缓存

- 日期：2026-09-05
- 来源：brainstorming 会话（需求逐项对齐并确认；四份调研报告支撑，全文见同目录附录文件）
- 状态：待实现（实现细节在 plan 中展开，本文只对齐需求、功能点与约定）
- 范围：新增 5 个新工具 + 批量下载与本地缓存 + 存量文档实测修正；**存量 11 个工具的参数与行为不变**（唯一例外：主连日线列名归一为英文列，见 §3.7，quant-chart 契约明确排除主连日线、无消费方）

## 一、背景与目标

用户为证券从业人员，做大类资产回测：先有宏观判断，再结合技术分析（上行通道、筹码密集区形成的支撑/压力、急浪等经验形态）落到具体操作，希望用数据验证这套判断。回测有两种情境：

1. **快速验证**：用自然语言描述宏观判断与技术形态，Agent 经 MCP 拉数、写回测、出结论。
2. **模拟盘**：命令行批量取数落本地，自写代码按真实约束（T+1、涨跌停、整手、佣金、印花税）跑历史。

本仓库定位为这两种情境的**统一数据源**。现有 11 个工具已覆盖 A/HK/US 股票、境内债券与可转债、国内期货/指数/ETF/期权、美股全球资产、世界银行宏观、arXiv 与代码归一化。本轮补齐对齐出来的四类能力：**美国/全球利率与波动率、汇率与国内商品现货、带生效区间的交易规则参数表、通用后处理与日线缓存**。

## 二、需求对齐结论

以下每一项都在头脑风暴中经用户确认，是本设计的边界：

| 议题 | 结论 |
|---|---|
| 谁消费数据 | Agent（MCP 对话式快速验证）+ CLI（批量取数供模拟盘/脚本），两种形态都要 |
| 数据缺口取舍 | 补：美国/全球利率与波动率、汇率与国内商品现货。不补：中国宏观月频流（世界银行年度数据够用）、北向/两融/龙虎榜等资金面数据 |
| 预处理边界 | 原始数据 + 少量"所有资产通用"的后处理（多标的按日期对齐合并、日↔周/月重采样）。**不做**均线/MACD/筹码分布等策略性指标——留给 Agent 或用户脚本 |
| 缓存程度 | 日线批量缓存：命令行按清单下载落本地，供模拟盘/脚本直接读。**MCP 查询不缓存**——数据接口不充当数据库，缓存由消费端按自身场景管理（用户决策）。不做分钟增量累积 |
| 回测标的层级 | 快速验证 + 模拟盘均以资产级为主，模拟盘含 A 股个股真实约束；期权与转债策略尚未开展，不做深度扩展 |
| 规则参数的角色 | 规则**执行**属于回测引擎，数据源只供**参数**。参数按生效区间版本化，同时服务两种回测情境：按历史真实参数跑（历史检视）、按现行参数套历史跑（新规则模拟） |
| 参数时效性 | 用户担心持续核验负担。解法：带生效区间的表天然不需要"检查是否最新"——回测日期落在哪个区间就取哪个值；每行附来源与核验日；变动极频繁的参数不入表 |
| 架构取向 | 用户关注**架构稳定性**与 **Agent 执行效率**。选定"最小增量 + 防膨胀措施"：沿用聚合工具模式，不引入统一查询入口 |
| 文档口径 | README/SKILL 中与实测不符的描述，一律以 2026-09-05 实测结果为准修正 |

## 三、能力清单

### 1. 全球利率与波动率查询（新工具 `query_global_rates`）

一个工具、四个子类，均为日频历史：

- **美债收益率**：2/5/10/30 年关键期限及 10Y-2Y 利差，自 1990 年起；3 个月等短端期限可查但仅近 4 年（免费源限制，如实标注）。
- **美联储利率**：采用纽约联储官方**有效联邦基金利率（EFFR）**日频序列。原因：akshare 的决议数据源自 2025-09 起停更，不可再依赖。
- **美元指数**：东财源自 1986 年起；该源在部分网络环境不可达（本机实测被拒），**内置自动回退**到 Yahoo。
- **VIX**：akshare 已无 VIX 接口（旧教程不可信），改为直连 CBOE 官方公开数据，自 1990 年起。

### 2. 汇率查询（新工具 `query_fx`）

- **官方中间价**：外汇局口径，25 个币种，自 1994 年起（2005 年汇改前仅美元/日元/港元有值）。报价单位沿用官方"100 外币 = X 人民币"，在返回摘要与文档中明示。
- **中行牌价**：含买入/卖出/现钞价与央行中间价，约 2012 年起；按日分页拉取，长区间较慢，如实标注。
- **离岸人民币与主要货币对**（USDCNH、EUR/USD、USD/JPY 等）：akshare 无免费历史接口，走 Yahoo；不可达时明确报错。

### 3. 国内商品现货查询（新工具 `query_spot`）

- **上金所贵金属**：Au99.99、Ag99.99、Au(T+D) 等 17 个品种，官方源，自 2016-12 起（接口深度上限约 10 年）。
- **生意社大宗现货**：约 100 个期货品种对应的现货价，**自带主力合约价与基差**，直接满足"现货与期货主连对照"的需求；自 2013 年起；逐日抓取很慢，因此**要求限定区间**（超过 1 年明确报错并提示缩小范围）。
- 99 期货源多数品种已限权（返回 401），不采用；长江有色/我的钢铁无免费历史接口，不做。

### 4. 交易规则参数表查询（新工具 `query_trading_rules`）

**它解决什么**：模拟盘与历史回测需要"某个日期当时生效的"制度参数（税费、涨跌幅、交收制度、保证金等），且用户不想承担持续核验最新值的负担。

**功能**：

- 按市场查询，给定 `as_of` 日期返回当天生效的全部参数；**不给日期即取现行参数**。于是"按历史真实规则跑"传历史日期、"按现行规则套历史"不传日期——一个参数覆盖两种情境。
- 每条参数带：生效起止、数值、费基口径（如过户费 2015-08 前按面值、之后按成交金额）、来源、核验日、置信度。
- 表随包分发、随版本更新，变动记入 CHANGELOG。

**收录范围**（有官方明确生效日、变更频率低、对回测结果影响大，共 11 类；完整区间数据见附录 B）：A 股印花税全部档位（含 2008 双边改单边、2023 减半）、过户费、经手费与证管费、红利税按持有期差别化、涨跌幅矩阵（主板/ST/创业板/科创板/北交所/新股首日/2016 熔断，含 **2026-07-06 主板 ST 改 ±10%**）、T+1 制度分界与 T+0 品类白名单、中金所股指期货保证金与平今手续费完整时间线、国债期货参数、融资保证金比例（含 **2026-01-19 回 100%**）、ETF 期权与股指期权费率、港股通红利税。

**明确处理方式**：

- 券商佣金、期货公司加收、两融利率等**市场化参数**：无官方时间线，只给"时代分段参考默认值"并标注为市场化估计，附官方上限（3‰）与最低 5 元规则；用户可在回测代码中覆盖。
- 商品期货合约级手续费/保证金：品种×合约×时段三维频繁变动，**不入表**；查询时返回引导性提示（同 `issuer_finance` 对城投发行人的处理风格），建议查交易所当日结算参数。
- 附录 B 标注"需核实"的条目，实现时先对照官方公告原文复核再入表。

### 5. 多序列对齐合并（新工具 `align_series`）

把本库产出的多份 CSV 按日期对齐合并成一张宽表：可指定各文件取哪一列（默认收盘价）、对齐方式（并集/交集）、是否前向填充、是否重采样到周/月（取期末值）。这是本轮唯一的后处理能力，覆盖"多资产归一化对比"和"日频与低频数据对齐"两个高频场景。

### 6. 批量下载与本地缓存（新能力）

- **命令行**：`local-datasource download --config 清单文件`。清单就是用户手工维护的"关注池"：每条写工具名与查询参数，可选起止日期。不带子命令时 `local-datasource` 仍直接启动 MCP server，向后兼容。
- **缓存目录**：按工具分目录、按查询参数生成可预测的文件名，CSV 落盘并附带元信息（覆盖区间、行数、最后拉取时间），回测脚本可直接读。
- **刷新语义**：当天已拉取的条目跳过；否则**全量重拉覆盖**（各源单标的全量耗时秒级，比尾部拼接简单可靠、无缝隙）；可强制全量。
- **MCP 查询不缓存**：查询工具保持纯数据接口，不读不写缓存目录。理由（用户决策）：数据接口不应数据库化，全量透明缓存没有必要且数据量会膨胀；需要缓存的回测工具应结合自身场景管理缓存，`download` 命令是唯一写缓存的入口。

### 7. 存量工具修正

- 期货主连"约 158 日"描述**已过时**，实测为全历史（详见第七、八节），仅改文档并加测试断言。
- A 股日线输出**本就含换手率**（小数口径）、流通股本与成交额，筹码分布近似计算的依赖已满足，只需在文档标注列语义。
- 小项：主连日线目前返回中文列名，与单合约的英文列不一致，顺手归一（quant-chart 契约明确排除主连日线，无消费方风险）。

## 四、使用体验约定

- **输出一致**：所有新工具与现有工具一样，结果写 CSV（自动建目录），返回行数、列数与前 5 行预览。
- **如实相告**：源的历史深度、单位口径（100 外币）、慢源预期耗时，写进工具描述与文档；请求超出源覆盖或参数非法时明确报错，**绝不静默降级**。
- **回退链透明**：有回退源的能力（美元指数）自动回退；全部源耗尽时报错文案含"该源在当前网络不可达"与建议动作。
- **描述预算**：每个工具描述控制在约 100 字（一句话用途 + 子类说明 + 输出约定），保障 Agent 读取效率与选择准确性。
- **错误处理沿用现有五步规范**：查参数 → 确认源 → 重试一次 → 上报；网络类失败不无限重试。

## 五、架构原则

- **最小增量**：一个资产类别一个聚合工具、子类分流，11 → 16 个工具；存量工具一行不改。
- **不引入统一查询入口（registry）**：各数据集参数天然异构，统一入口会退化成通用字典参数，丢失 schema 校验、伤害 Agent 准确性；当前规模也不需要。
- **防膨胀三措施**：provider 函数是唯一事实源、工具层永远薄封装（未来若迁 registry 只是机械搬移）；工具描述定预算；新数据优先落既有工具的子类而非新工具（本轮四个全球指标共用一个工具即首例）。
- **缓存用 CSV 而非 feather/parquet**：与"Agent 和 quant-chart 直接读 CSV"的消费形态一致，不制造格式隔阂。
- **MCP 工具保持纯数据接口**：不缓存、不充当数据库；缓存只产生于用户显式执行的 `download` 命令。
- **数据源选择原则**：akshare 有稳定接口就用 akshare；akshare 没有或已失效（VIX、EFFR）走官方公开数据直连；东财非 A 股端点（push2his 的全球指数/期货 K 线）在部分网络被拒——此轮实测把上一轮 spec"不依赖东财"的原则细化为"不依赖东财 push2his 非 A 股端点"（datacenter 端点实测可达），凡首选东财的能力必须有回退。

## 六、边界与非目标

本轮不做（记录在案，后续按需立项）：

- 中国宏观月频流数据（PMI/CPI/社融/LPR 等）；北向、两融、龙虎榜、股东户数等资金面数据
- 均线/MACD/筹码分布等指标层
- 期权、可转债策略的深度数据扩展
- 分钟线长历史累积（定时增量）
- Qlib/vectorbt 等框架格式导出
- 股指期货主连 2010-2016 缺失段的单合约拼接
- 商品期货合约级历史手续费/保证金表

## 九、验收标准

1. 全球利率：美债 10Y 收益率可回溯至 1990 年；EFFR 日频可查；美元指数在东财不可达的网络下自动回退成功；VIX 自 1990 年可查。
2. 汇率：美元中间价可回溯至 1994 年且摘要明示 100 外币口径；中行牌价可查；离岸与交叉盘在 Yahoo 可达时可查、不可达时报错含网络指引。
3. 现货：上金所 Au99.99 可查；生意社任一品种在 1 年内区间可查且返回基差列；超 1 年区间报错提示缩小范围。
4. 规则参数表：`as_of=2021-06-01` 查 A 股返回印花税 1‰（单边）、`as_of=2024-01-01` 返回 0.5‰、不传日期返回现行值；2026 年两项新变更（融资保证金、ST 涨跌幅）在表中；查商品期货返回引导性提示而非报错；"需核实"条目全部复核完毕。
5. 对齐合并：至少两份 CSV 可按并集/交集对齐、可前向填充、可重采样到周/月；缺列或无日期列时明确报错。
6. 缓存：按清单下载后缓存目录结构可预测；当天重复下载跳过；可强制全量；MCP 查询工具不读写缓存目录（保持纯接口）。
7. 存量零改动：11 个存量工具的注册名、参数与 `CoverageError` 语义不变，有回归断言；唯一输出变化是主连日线列名归一（§3.7，契约明确排除主连日线）。
8. 文档：第八节修正清单全部落地；主连深度与换手率语义有集成测试断言。
9. 单测不连网覆盖：规则表区间判定（含生效日边界）、缓存跳过与刷新判定、对齐合并全部路径、新工具参数归一化。

## 十、交付物与里程碑

| 风险 | 应对 |
