# 品种覆盖扩展设计：期货 / 指数 / ETF / 期权 / 个股分钟

- 日期：2026-08-28
- 来源：[Issue #1](https://github.com/jarvislee90s-dot/local-datasource/issues/1)
- 状态：待评审
- 范围：P0（期货、指数、个股分钟）+ P1 中的 ETF 与期权；**不含**国内宏观

## 一、背景与目标

本服务现有 7 个工具，覆盖股票（日线）、债券、可转债、世界银行宏观与 arXiv。投研中常见的大类品种仍无法查询：国内期货、指数、A股场内 ETF、期权，以及 A 股个股的分钟行情。

本轮为这些品种各提供一个查询工具，使用方式与现有工具完全一致：**按需拉取、免费数据源、无需 API Key、结果落盘 CSV 并附前 5 行预览**。不做定时采集、不做全品种下载、不建本地数据仓。

设计前已对全部候选接口做了连通性实测（2026-08-28，akshare 1.18.64），结论见"六、数据源与实测依据"。

## 二、能力清单

### 1. 期货查询（新工具）

查询国内期货，支持商品与金融期货。用户给出合约代码或主连代码即可。

- **行情**：日线与分钟两档。单合约日线为全历史（自上市，含持仓量）；主连日线约最近 158 个交易日；分钟约最近 4 个交易日，粒度可选 1/5/15/30/60 分钟。
- **合约清单**：给出品种代码（如 IM、RB），返回某交易日该品种的全部挂牌合约，含上市日、最后交易日等要素。

### 2. 指数查询（新工具）

查询国内指数日线与分钟，覆盖沪深交易所指数与中证系列指数。

- 日线：沪深指数（如上证 000852、深证 399xxx）自 2014 年起；中证系列（930xxx 等）走中证公司官网源，历史完整但拉取较慢（约 10 秒）。
- 分钟：腾讯源，约最近 8 个交易日，粒度可选；中证系列官网无分钟数据，请求时报错说明。

### 3. ETF 查询（新工具）

查询 A 股场内 ETF（如 510300 沪深300ETF）。

- 日线：新浪源，自 2012 年前后起全历史；该源不提供复权，返回原始价格（在文档中明示）。
- 分钟：腾讯源，约最近 8 个交易日，粒度可选。

### 4. 期权查询（新工具）

查询 ETF 期权（上交所 50ETF/300ETF/500ETF/科创50ETF）与股指期权（中金所 IO/HO/MO），本轮仅日线。

- **到期月份**：给出标的（如 50ETF、IO），返回当前可交易的到期月份。
- **合约清单**：给出标的，返回当月全部合约代码，便于先找代码再查行情。
- **单合约日线**：给出合约代码（如 10003889、IO2609C4200），返回该合约历史日线。

### 5. 个股分钟（现有工具增强）

股票查询工具增加分钟档：仅 A 股（港股/美股请求分钟时报错说明），腾讯源，约最近 8 个交易日，粒度可选；复权参数仅对日线有效。

## 三、使用体验约定

- **输入宽容**：代码大小写、交易所前后缀、常见分隔符（如 `IO2609-C-4200`）都能自动识别；识别不了时报错并提示正确格式。
- **输出一致**：所有查询结果写 CSV（utf-8-sig，自动建目录），返回行数、列数与前 5 行预览。
- **分钟深度如实相告**：请求区间早于数据源实际覆盖时，明确报错并给出补数指引（文案含覆盖截止日与"请从 Wind/终端导出 Excel 补数"），**绝不静默返回残缺数据**。覆盖深度按返回数据的实际最早时间戳动态判定，不写死天数——源站调整深度时无需改代码。
- **错误处理沿用现有五步规范**：查参数 → 确认源 → 重试一次 → 上报；网络类失败不无限重试。

## 四、架构原则

- 每个品种一个独立工具，与现有 query_bond / query_convertible_bond 的拆分模式一致；不改动存量工具的既有行为。
- 各品种的代码识别规则收在各自模块内，与现有股票代码归一化同构。
- 分钟深度校验做成一处共享实现，期货、指数、ETF、个股分钟四类共用，报错文案统一。
- 全部走新浪 / 腾讯 / 中证官网 / 交易所信息源；**不依赖东财**（实测本机被拒，详见第六节）。

## 五、边界与非目标

本轮不做（记录在案，后续按需立项）：

- 国内宏观指标（CPI/PMI/社融/M2/LPR）——另立项
- 期货主力换月映射——免费源需逐日拼装，成本效益不成立
- 期权分钟行情、期权 Greeks/基本信息表、T 型实时快照
- ETF 复权价
- 资金流 / 北向 / 两融 / 龙虎榜、场外基金净值、外汇/加密、Shibor/回购利率（原 issue P2）

已知限制（写入文档"注意"）：期货主连仅约 158 日；中证官网源慢约 10 秒；ETF 无复权；分钟历史深度受免费源天花板约束，更深历史靠用户补数。

## 七、验收标准

对齐 issue #1 验收标准，按本轮范围调整：

1. 期货：单合约日线返回全历史 CSV；分钟请求超出源覆盖时报错，文案含覆盖截止日与补数指引；合约清单可查。
2. 指数：000852 日线回溯至 2014；中证系列日线可查（慢源注意）；分钟超覆盖报错。
3. ETF：510300 日线自 2012 年起；分钟超覆盖报错。
4. 期权：三个能力（月份/清单/日线）均可用；SSE 合约清单降级路径有明确行为。
5. 个股分钟：可用，超覆盖报错；港股/美股请求分钟报错说明。
6. 上述"超覆盖报错"路径全部有不连网的单测；归一化规则有不连网的单测。
7. README 覆盖范围表、SKILL.md 工具速查表同步更新，分钟深度限制与慢源在"注意"中明示。
8. 完成后在 issue #1 评论实测修正结论并关闭。
